## Как переносился

- Последовательное применение `scripts/task{385,386,387,388,389}-patch.py`
  (копии kip8test) против kip8: **все якоря совпали** (385: 51 правка;
  386: 26; 387: 17+1+2 (index.html + WorkSchedule.gs +
  StatusCodesInit.gs); 388: 42; 389: 14 + 2 канонических фикса).
- `scripts/task385-389-transfer.py`: тесты синхронизированы из kip8test
  (102 файла, включая новые test-task385..389.js) с маппингом версий
  kipia-test-v617→kipia-v465 / guard v618→v466; run-all.js — восстановлен
  kip8-специфичный require('./test-task344.js'); test-task344.js — бамп
  v460→v465; sw.js — CACHE_VERSION v460→**v465**.
- Контроль: дифф kip8↔kip8test по index.html = **55 репо-специфичных
  строк** (ключи localStorage без префикса, isolateLocalStorage,
  комментарии kip8/kip8test — зоны Tasks 385–389 идентичны побайтово);
  sw.js дифф — только репо-специфика (суффикс -test).
