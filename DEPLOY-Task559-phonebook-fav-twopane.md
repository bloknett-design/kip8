## Что сделано (КЛИЕНТ — сервер не менялся)

- **Вкладка «Избранное» (десктоп ≥1024px, без поискового запроса) —
  ДВА ОКНА**, как вкладка «Все» (Task 540):
  - **Левое окно** `#pbList` — дерево «организации → подразделения»,
    построенное ТОЛЬКО по избранным контактам: организации и
    подразделения без избранного НЕ показываются, счётчики-пилюли —
    число избранных (Tasks 541/544 живы: зебра строк, счётчики одной
    колонкой, шеврон сворачивания — состояние `pbMasterCollapsed`
    ОБЩЕЕ с «Все», переживает смену вкладки);
  - **Правое окно** `#detailPanel` — избранные контакты выбранного
    подразделения (клик по строке группы) или всей организации
    (клик по строке организации — блоки по подразделениям,
    `pbRenderContactsHtml` как у «Все»); перетаскиваемая граница,
    ⇄-обмен панелей, ✕-закрытие, крошки — механизм Task 540/181.
- **JS**: `pbFavoritesFlat()` (избранные в порядке справочника) →
  `pbFavMasterBuildIndex()` (индекс только по избранным + валидация
  выбора) → `pbRenderFavMaster()` (левое окно) → `pbFavMasterOpen()`
  (правое окно + крошки c opts) / `pbFavMasterToggleOrg()` (шеврон).
  Выбор хранится **ПО ИМЕНАМ** `{header}` / `{header, group}` —
  индексы плывут, когда снятие ★ опустошает группу/организацию
  (у «Все» дерево статично, там индексы — Task 540).
- **Снятие ★ в правом окне**: карточка уходит из окна **НА МЕСТЕ**
  (DOM-удаление без переоткрытия панели — прокрутка не сбрасывается);
  левое дерево/счётчики обновляет `pbRender`; опустевшие
  группа/организация сбрасывают выбор и **закрывают правое окно**
  (валидация в `pbFavMasterBuildIndex`); добавление ★ достраивает
  дерево (организация появляется).
- **Крошки**: `setPhonebookBreadcrumbContent(org, grp, opts)` —
  новый третий аргумент `{openFn, orgIdx}`; без opts — прежнее
  поведение «Все» (`pbMasterOpen` / `pbDesktopSelected`).
- **Сбросы**: `pbMasterResetState()` и `pbInit()` сбрасывают
  `pbFavSelected` (смена таба, крошка «Телефонный справочник», ✕,
  повторный вход в раздел).
- **НЕ менялось**: мобильная версия (нижний бар, инлайн-список),
  поиск на любой вкладке (инлайн-результаты), вкладка «Все»,
  синхронизация избранного (Task 538), счётчики табов (Task 539),
  старт раздела на «Избранном» (Task 540).
