# Task 398 — перенос из kip8test (90a024c): атрибут `hidden` против CSS

**Дата:** 23.09.2026. **Перенос:** kip8test@90a024c → kip8. **SW:** kipia-v473 → **kipia-v474**.

## Что переносится

Заявка: «Почему в роли КИП ИОС видна кнопка "Работники" в разделе
Табель учёта рабочего времени, хотя доступа и перехода по ней нет?»

Причина: JS-гейт Task 395 ставил `#wsWorkersBtn` атрибут `hidden`
(уровень min), но CSS-правило `.ws-refresh-btn { display:
inline-flex }` ПЕРЕБИВАЛО браузерный UA-стиль `[hidden] { display:
none }` — кнопка оставалась на экране (rect 107×30), клик молча
отсекался `openWorkersPage` (min ≠ edit/view).

Фикс — ОДНО универсальное правило в начале `<style>` (index.html):

```css
[hidden] { display: none !important; }
```

Семантика атрибута `hidden` восстановлена по всему приложению; JS
не тронут (показ — всегда снятием атрибута). Побочно прикрыты
`#wsPrintBtn`/`#wsViewBtn` в граничных состояниях.
