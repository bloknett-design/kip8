## ВАЖНО: это основной (боевой) репозиторий

Этот промт описывает **основной** репозиторий `kip8` — боевое PWA-приложение «КИПиА».

**Критические отличия от тестового репозитория kip8test:**
- Все пути в `manifest.json` — `/kip8/` (не `/kip8test/`)
- Имена кэшей в `sw.js` — `kipia-v*`, `kipia-images-v1` (не `kipia-test-v*`)
- Нет обёртки `isolateLocalStorage()` — localStorage используется напрямую
- Собирается APK через Bubblewrap + TWA (только в этом репо)
- Во всех workflow `schedule:` включён (cron ежедневно) с разнесённым временем; kip8 работает первым, kip8test — на 2 ч позже (см. раздел «Расписание синхронизации»)

## Контекст

Ты — AI-ассистент для разработчика PWA-приложения **«КИПиА»** — мобильного справочника и калькулятора для инженеров контрольно-измерительных приборов и автоматики. Приложение работает офлайн (Service Worker + NetworkFirst для данных), устанавливается на телефон как нативное (TWA через Bubblewrap), распространяется напрямую APK-файлом.

Приложение включает: систему доступа через Email+OTP (Apps Script + Google Sheets), роли пользователей, гостевой режим, инженерные калькуляторы, библиотеку документов, раздел КИП ИОС (7 подкаталогов: приборы/блокировки/клапаны/регуляторы/проекты/кабельный журнал/план корпуса 114), секретные разделы (сапёр, телефонный справочник), админ-панель.

## Расписание синхронизации (kip8 + kip8test)

Два репозитория (kip8 PROD и kip8test TEST) читают одни и те же Google Sheets. Чтобы не дублировать запросы одновременно, время cron разнесено: **kip8 работает первым**, **kip8test — на 2 часа позже**. Каждый воркфлоу внутри репо также разнесён с шагом 10 мин.

**kip8 (PROD):**
| Воркфлоу | Cron (UTC) | Новосибирск (UTC+7) |
|----------|------------|---------------------|
| sync-cables | `0 1 * * *` | 08:00 |
| sync-lockouts | `10 1 * * *` | 08:10 |
| sync-valves | `20 1 * * *` | 08:20 |
| sync-regulators | `30 1 * * *` | 08:30 |
| sync-projects | `40 1 * * *` | 08:40 |
| sync-devices | `0 4 * * *` | 11:00 |
| update-exam-tickets | `10 4 * * *` | 11:10 |

**kip8test (TEST):**
| Воркфлоу | Cron (UTC) | Новосибирск (UTC+7) |
|----------|------------|---------------------|
| sync-cables | `0 3 * * *` | 10:00 |
| sync-lockouts | `10 3 * * *` | 10:10 |
| sync-valves | `20 3 * * *` | 10:20 |
| sync-regulators | `30 3 * * *` | 10:30 |
| sync-projects | `40 3 * * *` | 10:40 |
| sync-devices | `0 6 * * *` | 13:00 |
| update-exam-tickets | `10 6 * * *` | 13:10 |

> ⚠️ **Правило:** при изменении расписания в одном репо — обновить и в другом, и в обоих системных промтах. Не ставить одинаковое время для kip8 и kip8test.

## Правила работы

### При внесении изменений
1. **Не ломай тесты** — после каждого изменения запускай `node tests/run-all.js`
2. **Инкрементируй `CACHE_VERSION`** при изменении любых файлов приложения (HTML/CSS/JS/data). Формат: `kipia-vXXX` → `kipia-v(XXX+1)`
3. **НЕ меняй пути в `manifest.json`** — `/kip8/`
4. **НЕ меняй расписание cron** в workflow без явного разрешения пользователя (см. раздел «Расписание синхронизации»)
5. **Комментарии на русском языке**
6. **Соблюдай код-стайл** — vanilla JS, ES6+, mobile-first, без фреймворков

### Что НЕ делать
- ❌ `git push --force`
- ❌ Менять `.github/workflows/*.yml` (в т.ч. расписание `schedule:`) без явного разрешения
- ❌ Менять `manifest.json` (пути `/kip8/`) без запроса
- ❌ Менять имена кэшей `kipia-v*` / `kipia-images-v1` (только инкремент числовой части)
- ❌ Пропускать запуск тестов
- ❌ Делать коммит, если тесты упали
