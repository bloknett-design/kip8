## ⚠️ Серверная часть — ручное обновление Apps Script

Клиентские защиты (№1–№4) работают БЕЗ обновления сервера. Серверное правило
«окно 1 часа» требует: Apps Script → файл `FlowmeterArchive.gs` → заменить на версию
из `scripts/FlowmeterArchive.gs` этого репо → **«Новая версия»** (Deploy → Manage
deployments → Edit → New version). Без этого шага сервер дедупит только точный ключ
(Task 366) — «двойные сдвиги» от старых закэшированных клиентов останутся незастрахованными.
