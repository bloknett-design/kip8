## ✅ ЧТО ДЕЛАТЬ ПОЛЬЗОВАТЕЛЮ (всего 1 шаг)

### Шаг 1. Обновить PWA в браузере — `Ctrl+Shift+R` ×2

1. Откройте https://bloknett-design.github.io/kip8/
2. Дважды нажмите **Ctrl+Shift+R** (Windows/Linux) или **Cmd+Shift+R** (Mac),
   между нажатиями подождите ~5 секунд.
3. Появится новый Service Worker (`kipia-v408`) — страница перезагрузится сама
   (или обновите ещё раз обычным F5).
4. Проверка: «График работы» → в субнавигации появилась вкладка **«Отпуска**».

Пользователи Android-приложения (APK/TWA) получат обновление при следующем
открытии — Service Worker обновляется в фоне, кэш v408 подтянется автоматически
(может потребоваться закрыть/открыть приложение 1-2 раза в течение суток).

с Task 245: `https://script.google.com/macros/s/AKfycbyt2sjb…/exec`
(константа `KipAuth.WEB_APP_URL` в index.html).

Это развёртывание вы уже обновили при отладке «Unknown action» (Task 283):
код с роутингом отпусков (`listVacations` / `addVacation` / `deleteVacation`)

→ **Никаких действий в редакторе Apps Script не требуется.**

Справочные копии серверных файлов в репо (`scripts/*.gs`) актуальны на случай
будущей ручной синхронизации:

| Файл в репо | Назначение |
