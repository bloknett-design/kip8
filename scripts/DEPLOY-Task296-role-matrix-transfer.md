## Как теперь менять права (полный цикл, без деплоев)

1. Таблица KIP8_Access → лист **matrix** → поставить/снять галочку.
2. Сервер подхватит ≤ 5 минут (кэш) — или мгновенно, если выполнить
   `roleMatrixInvalidateCache()` в редакторе Apps Script.
3. Клиент (открытый сайт) — при входе, каждой загрузке страницы или
   ближайшем heartbeat (≤ ~10 минут), либо просто после F5.
4. Действует на **оба сайта сразу** (kip8 и kip8test — общий бэкенд).

## Если что-то пошло не так

- Все закрытые разделы стали недоступны всем → матрица не читается
  (fail-closed по дизайну). Причина — в редакторе Apps Script:
  `roleMatrixDebug` (лист/роль/кэш) или `rmGateStatus` (шлюз).
- Кнопка «Ввести показания» не появилась у нужной роли → проверьте
  галочку `flowmeter.input` в листе matrix. Диагностика в браузере
  (F12 → Console): `KipAuth._serverAccess` (что прислал сервер),
  `KipAuth._serverPerm('flowmeter.input')` — true / false / null
  (null = карта не получена, работает легаси-список — сеть/старый
  сервер; не поломка, сервер всё равно гейтит каждый запрос).
- Предупреждение `[KipAuth._fetchMyAccess]` в Console — карта не
  получена (сеть/старый сервер), работает легаси-карта. Не поломка.
