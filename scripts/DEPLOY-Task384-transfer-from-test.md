## ⚠️ Серверные шаги — выполнить вручную в Apps Script

Новые эндпоинты требуют обновления Apps Script (ОДИН бэкенд на kip8 и
kip8test — если уже сделано для kip8test по DEPLOY-Task384-emp-card-crud-edit.md,
повторно НЕ нужно). Пока сервер не обновлён, кнопки «Сохранить» в режимах
правки данных сотрудника и правки отпуска вернут ошибку
`Unknown action: workSchedule.updateEmployee / updateVacation` — клиент
покажет её в тосте, ничего не сломается.

1. Открыть редактор Apps Script (проект развёртывания `AKfycbyt…` — тот же,
   где `Code.gs`, `Utils.gs`, `WorkSchedule.gs`).
2. **`Code.gs`** — в `doPost` после `case 'workSchedule.deleteVacation':`
   добавить два case (копия из репозитория `scripts/Code.gs`):
   ```js
   case 'workSchedule.updateEmployee':
     return _json(WorkSchedule.updateEmployee(payload));

   case 'workSchedule.updateVacation':
     return _json(WorkSchedule.updateVacation(payload));
   ```
3. **`WorkSchedule.gs`** — заменить целиком на версию из репозитория
   `scripts/WorkSchedule.gs` (добавлены методы `updateEmployee` — после
   `dismissEmployee`, и `updateVacation` — после `addVacation`; остальное
   без изменений).
4. Нажать **«Сохранить»**, затем **«Выполнить» → «Новое развёртывание»**
   (или Управление развёртываниями → Изменить → Новая версия) — тип
   «Веб-приложение», доступ «Любой», выполнение «от моего имени».
